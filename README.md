# 🚀 Ritanshu Mahajan — Developer & AI Portfolio

A modern, high-performance personal portfolio tailored for **Software Development Engineering (SDE)** and **AI / Machine Learning** roles.

Built with clean semantic HTML5, modern Tailwind CSS, Lucide / FontAwesome icons, Canvas interactive particle physics, and pure JavaScript.

---

## 🌟 Key Features

1. **Dual Focus (SDE + AI/ML)**:
   - Dedicated sections highlighting strengths in both software engineering (CS fundamentals, backend architecture, databases) and AI/ML (deep learning, computer vision, quantized inference).
2. **Interactive Neural Network Canvas**:
   - Dynamic canvas background rendering connected neural synapses that interact with the mouse cursor.
3. **Interactive Developer Terminal (CLI)**:
   - An interactive terminal widget where recruiters and engineers can test commands (`whoami`, `skills`, `projects`, `hackathons`, `education`, `contact`, `sudo hire`).
4. **Interactive Deep-Dive Modals**:
   - Detailed modal views for key projects (*Sign Language Recognition System*, *Gurukul*, *EdgeEdu*, *GeneGuard*) explaining the architecture, algorithmic optimizations, and metrics.
5. **Project & Skills Filter**:
   - Filter projects instantly between *All*, *AI & Machine Learning*, *Full-Stack & Backend*, and *Hackathon Innovations*.
6. **Built-in ATS Web Resume (`resume.html`)**:
   - A clean ATS-optimized resume matching the submitted resume, with a 1-click **"Print / Save as PDF"** feature.
7. **Instant Clipboard & Toast Notifications**:
   - 1-click copy for email (`ritanshupm@gmail.com`) and phone (`+91-9579036245`) with floating toast confirmations.
8. **Mobile-First & Ultra Responsive**:
   - Clean navigation, adaptive grids, and smooth scrolling across all devices.

## ⚡ How to Run Locally

### Option 1: Open Directly in Any Browser
Simply double-click `index.html` or drag it into Chrome, Edge, or Firefox. No build tools or installation required!

### Option 2: Using Python's Built-in HTTP Server
Run the following in PowerShell from this directory:
```powershell
python -m http.server 3000
```
Then visit `http://localhost:3000` in your browser.

### Option 3: Using Node / npx
```bash
npx serve .
```

## 🌐 Free 1-Click Deployment

### 1. GitHub Pages (Recommended)
1. Initialize git in this folder and push to a new GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/Ritanshu1104/<repo-name>.git
   git push -u origin main
   ```
2. On GitHub, go to **Settings > Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your site will be live at `https://ritanshu1104.github.io/<repo-name>/`!

### 2. Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this folder, or import the GitHub repository on [vercel.com](https://vercel.com).
3. Deploys in 15 seconds with automatic HTTPS and global CDN.
